# transportDisorderedFilamentArray1D
Code for computing steady-state distributions of active particles moving on a disordered array of parallel filaments.

Example calculations:
(1) runLandscapeExampleRandConfig.m
Generate a random configuration of filaments and compute the effective landscape and steady-state particle distribution.

(2) runLandscapeExampleUserInput.m
Using a pre-specified filament configuration, compute the effective landscape and steady-state particle distribution.

(3) runSimulations.m
Run a stochastic simulation of particles moving on a randomly generated filament array. Show a video of snapshots. Plot the final distribution as a histogram.
